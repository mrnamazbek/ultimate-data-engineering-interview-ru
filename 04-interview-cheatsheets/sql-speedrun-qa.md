# Экспресс-подготовка: Топ-50 вопросов и ответов по SQL и базам данных

Этот блиц-справочник предназначен для быстрого повторения ключевых понятий по SQL и реляционным базам данных за 1–2 часа до технического интервью.

---

### 1. Что такое первичный ключ (Primary Key)?
Столбец или набор столбцов, который однозначно идентифицирует каждую строку в таблице. Первичный ключ не может содержать значений `NULL` и дубликатов.

### 2. Может ли таблица иметь несколько первичных ключей?
Нет. В таблице может быть строго один первичный ключ. Однако он может состоять из нескольких столбцов (составной первичный ключ).

### 3. Что такое составной первичный ключ (Composite Primary Key)?
Первичный ключ, сформированный из двух или более столбцов, комбинация значений которых уникальна (например, связка `order_id` и `product_id` в таблице позиций заказа).

### 4. Что такое индекс (Index)?
Специализированная структура данных (обычно B-Tree), ускоряющая поиск и выборку строк ценой дополнительного места на диске и замедления операций записи (`INSERT`, `UPDATE`, `DELETE`).

### 5. В чем разница между кластерным и некластерным индексами?
- **Кластерный индекс**: физически сортирует и хранит сами строки данных на диске. В таблице может быть только один.
- **Некластерный индекс**: хранится отдельно от таблицы и содержит указатели (адреса) на физические строки данных. Таблица может иметь много некластерных индексов.

### 6. Как удалить индекс в SQL?
`DROP INDEX index_name ON table_name;` (синтаксис в зависимости от СУБД: в PostgreSQL `DROP INDEX index_name;`).

### 7. Что такое ограничения (Constraints) в SQL?
Правила, задаваемые для столбцов таблицы для обеспечения целостности данных: `NOT NULL`, `UNIQUE`, `PRIMARY KEY`, `FOREIGN KEY`, `CHECK`, `DEFAULT`.

### 8. В чем разница между UNIQUE и PRIMARY KEY?
`PRIMARY KEY` может быть только один в таблице и строго запрещает `NULL`. Ограничений `UNIQUE` может быть несколько, и они допускают значения `NULL` (в большинстве СУБД допускается несколько `NULL`, в SQL Server — только один).

### 9. Как добавить внешний ключ (FOREIGN KEY)?
`ALTER TABLE orders ADD CONSTRAINT fk_user FOREIGN KEY (user_id) REFERENCES users(id);`

### 10. Что такое ограничение DEFAULT?
Указывает значение по умолчанию, которое подставляется в столбец, если при вставке (`INSERT`) значение не было передано явно.

### 11. Что такое нормализация данных?
Процесс организации структуры таблиц для устранения избыточности и предотвращения аномалий вставки, обновления и удаления данных.

### 12. Какие основные нормальные формы существуют?
- **1NF**: атомарность значений, отсутствие повторяющихся групп колонок, уникальность строк.
- **2NF**: соответствие 1NF + отсутствие частичной зависимости атрибутов от составного ключа.
- **3NF**: соответствие 2NF + отсутствие транзитивных зависимостей неключевых атрибутов.

### 13. Что такое денормализация?
Осознанное объединение таблиц и внесение избыточности для ускорения выполнения аналитических запросов за счет исключения тяжелых `JOIN`.

### 14. Как извлечь все записи из таблицы?
`SELECT * FROM table_name;` (в продакшне рекомендуется перечислять только необходимые столбцы).

### 15. Как отфильтровать строки по условию?
С помощью секции `WHERE`: `SELECT * FROM employees WHERE salary > 50000;`.

### 16. Как отсортировать данные?
С помощью секции `ORDER BY`: `ORDER BY salary ASC` (по возрастанию, по умолчанию) или `ORDER BY salary DESC` (по убыванию).

### 17. В чем разница между WHERE и HAVING?
`WHERE` фильтрует отдельные строки до группировки, а `HAVING` фильтрует уже сгруппированные данные по результатам агрегатных функций.

### 18. Что такое INNER JOIN?
Соединение, возвращающее только те строки, для которых найдено совпадение условий в обеих таблицах.

### 19. Что такое LEFT JOIN?
Соединение, возвращающее все строки из левой таблицы и совпадающие строки из правой (при отсутствии совпадений подставляется `NULL`).

### 20. Что такое транзакция в SQL?
Неделимый логический блок операций над базой данных: либо выполняются все операции целиком, либо ни одна.

### 21. Как управлять транзакцией?
- Начать: `BEGIN TRANSACTION;` (или `START TRANSACTION;`).
- Зафиксировать: `COMMIT;`.
- Откатить: `ROLLBACK;`.

### 22. Какие базовые агрегатные функции вы знаете?
`COUNT()` (количество), `SUM()` (сумма), `AVG()` (среднее), `MIN()` (минимум), `MAX()` (максимум).

### 23. Разница между скалярными и табличными функциями?
- Скалярная функция возвращает одно единственное значение (`UPPER()`, `ROUND()`).
- Табличная функция возвращает набор строк (таблицу), с которой можно работать в секции `FROM`.

### 24. Что такое хранимая процедура (Stored Procedure)?
Скомпилированный именованный набор SQL-инструкций, хранящийся на сервере базы данных и поддерживающий логику ветвления, циклы и транзакции.

### 25. Как вызвать хранимую процедуру?
`EXEC procedure_name;` (в SQL Server) или `CALL procedure_name();` (в PostgreSQL/MySQL/Oracle).

### 26. Что такое триггер (Trigger)?
Специальная хранимая процедура, автоматически вызываемая СУБД при наступлении определенного события (`INSERT`, `UPDATE`, `DELETE`) над таблицей.

### 27. Что такое представление (View)?
Виртуальная таблица, представляющая собой сохраненный SQL-запрос. Данные физически не хранятся и вычисляются в момент обращения.

### 28. Можно ли обновлять данные через View?
Да, если представление простое (построено на одной таблице, без `DISTINCT`, `GROUP BY`, агрегатных функций и `UNION`).

### 29. Как оптимизировать медленный SQL-запрос?
1. Изучить план выполнения через `EXPLAIN ANALYZE`.
2. Создать недостающие индексы под фильтры `WHERE` и поля `JOIN`.
3. Заменить `SELECT *` на конкретные поля.
4. Избегать функций над индексированными колонками в блоке `WHERE` (например, `WHERE YEAR(date) = 2026` ломает использование индекса).
5. Использовать `EXISTS` вместо `IN` для подзапросов.

### 30. Что такое план выполнения запроса (Execution Plan)?
Внутренний план действий, построенный оптимизатором СУБД: последовательность сканирования таблиц (`Seq Scan` или `Index Scan`), типы соединений (`Hash Join`, `Nested Loop`, `Merge Join`) и оценка стоимости (Cost).

### 31. Что такое курсор (Cursor) в базах данных?
Механизм построчной обработки результирующего набора данных. В SQL-разработке курсоров следует избегать, отдавая предпочтение векторным операциям над множествами (Set-based operations).

### 32. Что такое свойства ACID?
Atomicity (Атомарность), Consistency (Согласованность), Isolation (Изолированность), Durability (Долговечность).

### 33. В чем разница между DELETE и TRUNCATE?
`DELETE` — это DML (построчное удаление, поддерживает `WHERE`, пишет в лог, медленное). `TRUNCATE` — это DDL (мгновенная очистка всей таблицы, сбрасывает счетчик автоинкремента, не вызывает строчные триггеры).

### 34. Что такое оконная функция (Window Function)?
Функция, выполняющая расчет по набору связанных строк (окну) без сворачивания результирующих строк в одну.

### 35. Какие главные компоненты оконной функции?
Ключевое слово `OVER`, секции `PARTITION BY` (разбиение на группы), `ORDER BY` (сортировка внутри окна) и спецификация фрейма (`ROWS BETWEEN`).

### 36. Что делает функция `ROW_NUMBER()`?
Присваивает строго последовательный уникальный номер строкам внутри каждой партиции: `1, 2, 3, 4`.

### 37. Что делает функция `RANK()`?
Присваивает ранг строкам. Одинаковым значениям присваивается одинаковый ранг, при этом следующие номера рангов **пропускаются** (например: `1, 2, 2, 4`).

### 38. Чем `DENSE_RANK()` отличается от `RANK()`?
`DENSE_RANK()` не делает пропусков в нумерации рангов (например: `1, 2, 2, 3`).

### 39. Что делает функция `NTILE(n)`?
Делит строки внутри окна на $n$ равных групп и возвращает номер корзины (от 1 до $n$) для каждой строки.

### 40. Как `SUM()` используется в качестве оконной функции?
`SUM(amount) OVER (PARTITION BY user_id)` — вычисляет общую сумму по пользователю, выводя ее в каждой строке без группировки.

### 41. Что делает `AVG()` в оконной функции?
Вычисляет среднее значение по окну (например, для расчета скользящего среднего или отклонения текущей строки от среднего значения по отделу).

### 42. Что делает функция `LAG()`?
Возвращает значение из предыдущей строки на заданное смещение назад: `LAG(salary, 1) OVER (ORDER BY date)`.

### 43. Что делает функция `LEAD()`?
Возвращает значение из следующей строки на заданное смещение вперед.

### 44. Что такое спецификация фрейма (Frame Specification)?
Указание точных границ строк внутри окна относительно текущей строки (`ROWS BETWEEN ... AND ...`).

### 45. Какой фрейм применяется по умолчанию, если указан `ORDER BY`?
`RANGE BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW`.

### 46. Как задать пользовательский скользящий фрейм?
`ROWS BETWEEN 3 PRECEDING AND 3 FOLLOWING` (три строки до текущей и три строки после).

### 47. Разница между ROWS и RANGE во фреймах?
`ROWS` оперирует физическими строками, а `RANGE` оперирует логическими значениями столбца сортировки.

### 48. Как рассчитать накопительный итог (Running Total)?
`SUM(amount) OVER (ORDER BY date ROWS BETWEEN UNBOUNDED PRECEDING AND CURRENT ROW)`

### 49. Можно ли использовать несколько оконных функций в одном запросе?
Да. Каждая функция может иметь собственное независимое окно (`OVER (...)`).

### 50. Назовите 3 практических бизнес-сценария для оконных функций.
1. Поиск топ-3 товаров в каждой категории по объему продаж (`DENSE_RANK()`).
2. Расчет темпа прироста выручки по сравнению с прошлым месяцем (`LAG()`).
3. Дедупликация сырых логов с сохранением последней версии записи (`ROW_NUMBER()`).
