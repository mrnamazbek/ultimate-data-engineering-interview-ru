# Экспресс-подготовка: Топ-30 вопросов и ответов по Apache Spark и PySpark

Краткий конспект ключевых концепций Apache Spark для повторения перед техническим интервью.

---

### 1. Почему Apache Spark вытеснил Hadoop MapReduce?
MapReduce после каждой промежуточной стадии записывает данные на жесткие диски (HDFS), вызывая колоссальные накладные расходы на I/O. Spark выполняет вычисления в оперативной памяти (In-Memory) и строит оптимизированный граф выполнения (DAG), что делает его в 10–100 раз быстрее.

### 2. Что такое SparkContext и SparkSession?
- `SparkContext`: точка входа в низкоуровневый Spark Core (работа с RDD).
- `SparkSession` (появилась в Spark 2.0): единая точка входа для всех модулей: Spark SQL, DataFrame, Streaming, объединяющая `SparkContext`, `SQLContext` и `HiveContext`.

### 3. Чем RDD отличается от DataFrame?
- **RDD**: низкоуровневая распределенная коллекция Java/Python объектов без информации о схеме. Нет автоматической оптимизации.
- **DataFrame**: распределенная таблица с именованными колонками и строгими типами данных. Оптимизируется движком Catalyst и компилируется в эффективный машинный код проектом Tungsten.

### 4. В чем разница между узкими (Narrow) и широкими (Wide) трансформациями?
- **Узкие (Narrow)**: выполняются локально внутри одного исполнителя без сетевого обмена (`map`, `filter`).
- **Широкие (Wide)**: требуют перемешивания данных между всеми воркерами кластера по сети — **Shuffle** (`groupByKey`, `reduceByKey`, `join`, `distinct`).

### 5. Что такое Lazy Evaluation (ленивые вычисления)?
Трансформации не производят реальных расчетов в момент написания кода. Spark лишь строит логический план (Lineage Graph). Физические вычисления запускаются только при вызове действия (**Action**).

### 6. Назовите 5 примеров действий (Actions) в Spark.
`count()`, `collect()`, `show()`, `take()`, `saveAsTextFile()` / `write.parquet()`.

### 7. В чем разница между `repartition()` и `coalesce()`?
- `repartition(N)`: всегда выполняет полный сетевой Shuffle, равномерно распределяет данные, может как увеличивать, так и уменьшать число партиций.
- `coalesce(N)`: объединяет существующие партиции на нодах без Shuffle, работает только на уменьшение количества разделов.

### 8. Чем `groupByKey` хуже `reduceByKey` в Spark Core?
`groupByKey` передает по сети все значения по каждому ключу без предварительной агрегации, переполняя память. `reduceByKey` сначала агрегирует данные локально на каждом маппере (Map-side combine) и передает по сети уже свернутые промежуточные суммы.

### 9. В чем разница между `cache()` и `persist()`?
`cache()` — это вызов `persist()` со стандартным уровнем хранения `MEMORY_AND_DISK`. Метод `persist()` позволяет явно выбрать уровень: `MEMORY_ONLY`, `MEMORY_ONLY_SER`, `OFF_HEAP` и др.

### 10. Что делает Catalyst Optimizer?
Оптимизатор запросов в Spark SQL. Выполняет анализ, проталкивание предикатов к источнику (Predicate Pushdown), отсечение ненужных колонок (Column Pruning), свертку констант и выбор оптимального физического плана соединений.

### 11. Что такое Project Tungsten?
Инициатива по оптимизации CPU и памяти: компактное представление данных вне кучи JVM (Off-heap binary encoding) без накладных расходов сборщика мусора (GC) и генерация байт-кода на лету (Whole-stage code generation).

### 12. Что такое Broadcast Join и когда он применяется?
Алгоритм соединения, при котором одна маленькая таблица (по умолчанию < 10 МБ) полностью копируется в память всех исполнителей (Executors). Позволяет выполнить `JOIN` без дорогостоящего сетевого Shuffle большой таблицы.

### 13. Что такое Data Skew (перекос данных) и как с ним бороться?
Ситуация, когда одна или несколько партиций содержат в разы больше строк, чем остальные, из-за неравномерного распределения значений ключа. Решения: техника засолки ключей (Key Salting), фильтрация пустых ключей, включение Adaptive Query Execution (AQE).

### 14. Как работает Key Salting?
К популярному ключу искусственно дописывается случайный префикс (например, `key_0`, `key_1`), а вторая соединяемая таблица размножается (`explode`), после чего соединение проходит равномерно без перекосов.

### 15. Что такое Dynamic Partition Pruning (DPP)?
Оптимизация в Spark 3.0, которая отсекает ненужные партиции таблицы фактов на основе динамических результатов фильтрации таблицы измерений еще до чтения с диска.

### 16. Что такое Adaptive Query Execution (AQE)?
Механизм перестроения плана запроса прямо во время выполнения на основе фактического размера данных после Shuffle (динамическое объединение партиций, устранение перекосов, замена SortMergeJoin на BroadcastJoin).

### 17. Что такое Accumulators (аккумуляторы) в Spark?
Специальные распределенные переменные, доступные только для добавления (write-only для воркеров, read-only для драйвера). Используются для подсчета глобальных счетчиков (например, числа битых строк).

### 18. Что такое Broadcast Variables?
Неизменяемые переменные, которые отправляются драйвером на каждый рабочий узел кластера ровно один раз (кэшируются на ноде), а не пересылаются с каждой отдельной задачей.

### 19. Что такое Spill to Disk?
Сброс промежуточных данных из оперативной памяти на диск во время Shuffle или сортировки, когда выделенного объема JVM Heap недостаточно. Сигнализирует о необходимости тюнинга памяти или увеличения числа партиций.

### 20. Как устроена память Spark Executor?
Память разделена на Reserved Memory (300 МБ), User Memory (40%) и Spark Memory Pool (60%), который делится динамически между Storage Memory (кэш) и Execution Memory (буферы Shuffle).

### 21. Почему нельзя вызывать `df.collect()` в продакшне?
`collect()` передает весь результирующий датасет со всех узлов кластера в память одного управляющего процесса (Driver). Если объем данных превышает память драйвера, приложение падает с `OutOfMemoryError`.

### 22. Чем `select` отличается от `selectExpr`?
`selectExpr` позволяет использовать стандартные SQL-выражения в строковом формате: `df.selectExpr("price * 1.2 as price_with_vat", "upper(name)")`.

### 23. Как создать временное SQL-представление из DataFrame?
`df.createOrReplaceTempView("temp_orders")`, после чего к нему можно обращаться через `spark.sql("SELECT * FROM temp_orders")`.

### 24. Что такое Watermark в Spark Structured Streaming?
Порог допустимого опоздания данных относительно Event Time, после превышения которого закрываются агрегационные окна и освобождается память буфера состояний (State Store).

### 25. Какие бывают режимы вывода (Output Modes) в Structured Streaming?
- `Append`: выводятся только новые строки (подходит для простых вставок).
- `Complete`: выводится вся результирующая таблица целиком (для агрегаций).
- `Update`: выводятся только те строки, которые изменились с момента предыдущего триггера.

### 26. Зачем нужен Checkpointing в Structured Streaming?
Запись состояния потока и смещений (offsets) в надежное хранилище (S3/HDFS). При падении приложения Spark перезапускается с момента последней зафиксированной точки без потерь данных.

### 27. Чем Sort-Merge Join отличается от Shuffle Hash Join?
- **Sort-Merge Join**: выполняет Shuffle данных по ключу, затем сортирует обе таблицы на воркерах и сливает их. Надежен при любых объемах данных.
- **Shuffle Hash Join**: строит хэш-таблицу по меньшей из сторон в памяти воркера. Быстрее, если одна из сторон умещается в RAM воркера.

### 28. Что такое Lineage Graph в RDD?
Граф происхождения, фиксирующий последовательность трансформаций, приведших к текущему состоянию датасета. Позволяет автоматически восстановить утерянную партицию при падении воркера без полного перезапуска задачи.

### 29. Зачем нужны Pandas UDF (Vectorized UDFs)?
Для вызова Python-функций над блоками данных через Apache Arrow без построчной сериализации между JVM и Python, что ускоряет выполнение до 100 раз.

### 30. Как определить оптимальное число партиций при записи в S3/HDFS?
Размер итогового файла должен составлять 128–512 МБ. Общий объем данных делят на 256 МБ: если датасет весит 25.6 ГБ, оптимально установить 100 партиций (`df.coalesce(100)`).
